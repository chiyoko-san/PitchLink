# PitchLink サイトマップ

各ページの役割と、誰が・何のために使うかを整理したものです。「営業電話をなくし、必要な会社に必要なツールが届く」というサービスの目的に沿って、ページを4つのグループに分けています。

---

## 1. 公開・集客系（外部の人が見るページ）

### トップページ `/`
- **ファイル**: LandingPage.tsx ／ **状態**: 実装済み
- **誰が見る**: サービスを知らない見込み客（受け手企業・売り手の両方）
- **目的**: PitchLinkが何かを伝え、登録（無料で始める）かログインへ誘導する入口。
- **主な導線**: 「無料で始める」「ログイン」→ ログインページ／公開ページデモ・管理画面デモへのリンク。

### 公開ページ `/company/:slug`
- **ファイル**: CompanyPage.tsx ／ **状態**: 実装済み
- **誰が見る**: 売り手（営業担当者）
- **目的**: 受け手企業ごとの提案受付窓口。受け手が出した「受け取り条件」を売り手が読み、条件に沿った資料を送付フォームから提出する。**このサービスの起点**で、電話の代わりになる場所。
- **ポイント**: slug は企業ごとの固有URL。受け手企業がHPのフッター等に設置して使う。

### タイムライン `/company/:slug/timeline`
- **ファイル**: TimelinePage.tsx ／ **状態**: 実装済み（要確認）
- **目的**: 公開ページに紐づく時系列表示。役割が公開ページと重複する場合は統合を検討。

---

## 2. 認証・課金系

### ログイン／新規登録 `/login`
- **ファイル**: LoginPage.tsx ／ **状態**: 実装済み（認証ロジックは未接続）
- **誰が使う**: 受け手企業・売り手の両方（同じ画面でログイン）
- **目的**: ログインと新規登録をタブで切替。メール＋パスワードとGoogleログインに対応。新規登録時にデータの匿名化利用への同意を明示。
- **未接続**: 実際の認証はバックエンドかClerk/Auth.jsに繋ぐ必要あり。

### 料金・支払い `/billing`
- **ファイル**: BillingPage.tsx ／ **状態**: 実装済み（決済は未接続）
- **誰が使う**: 受け手企業（有料版を検討するユーザー）
- **目的**: 有料プランの内容・請求額を提示し、支払い情報を入力させる。無料版の制限（古い資料の閲覧・部署8個以上）を解除する課金導線。
- **未接続**: 決済処理はStripe等に繋ぐ必要あり。特定商取引法の表記が本番前に必須。

---

## 3. 受け手企業の管理画面（ログイン後）

### ダッシュボード `/dashboard`
- **ファイル**: DashboardPage.tsx ／ **状態**: 実装済み
- **誰が使う**: 受け手企業
- **目的**: 届いた提案を自分のペースで選別する中心画面。サイドバーで以下を切り替える。
  - **受信トレイ**: 届いた提案を一覧。保存・却下（理由メモつき）・選別。無料版は直近5件まで、古い資料はロック（有料で解除）。
  - **部署設定**: 部署ごとの受け取り設定。無料版は8個まで。
  - **会社設定**: 公開URL、受け取り条件の編集、会社情報。
- **サイドバーからの導線**: 料金プラン・ヘルプ・ログアウト。

### 提案詳細 `/pitch/:id`
- **ファイル**: PitchDetailPage.tsx ／ **状態**: 実装済み
- **誰が使う**: 受け手企業
- **目的**: 個別の提案をじっくり見る専用ページ。資料・動画、「御社オリジナル」セクション、連絡先を表示。有料版では資料のページ別閲覧時間（売り手向け分析）を確認できる。

## 4. 静的・法的ページ（フッターから参照／未実装）

以下はフッターにリンクを用意済みだが、ページ本体はまだ無い。クリックすると空になる。順次作成が必要。

| ページ | パス | 目的 | 優先度 |
|---|---|---|---|
| お問い合わせ | `/contact` | 問い合わせフォーム | 中 |
| よくある質問 | `/faq` | FAQ。サイドバーの「ヘルプ」もここへ | 中 |
| 使い方ガイド | `/guide` | 操作説明 | 低 |
| 利用規約 | `/terms` | 規約。匿名化データ利用の明記を含む | **高** |
| プライバシーポリシー | `/privacy` | 個人情報の扱い | **高** |
| 特定商取引法に基づく表記 | `/legal` | 事業者情報・料金・解約条件 | **高（課金前必須）** |

## 全体の流れ（ユーザー視点）

**受け手企業**: トップ → 新規登録 → ダッシュボードで受け取り条件を設定 → 公開URLを自社HPに設置 → 届いた提案を受信トレイで選別 → 必要なら有料版へ

**売り手**: 受け手企業の公開URLを開く → 受け取り条件を確認 → 条件に沿った資料を送付 →（有料の受け手なら）閲覧状況がフィードバックされる
